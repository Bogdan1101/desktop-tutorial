# Отклик на попадание: до и после

Chromium с программной отрисовкой. Запись в реальном времени здесь невозможна (кадр рисуется дольше 33 мс),
поэтому GIF собраны **покадрово**: каждый кадр продвигает игру ровно на 33 мс игрового времени (обычная
скорость, 30 кадров/с), между кадрами — снимок. В GIF кадр показывается 30 мс, то есть почти в реальном времени.
Боты остановлены, башни не стреляют; удары вызываются сценарием, урон и время атаки — игровые.

- `duel-*.gif` — слева ДО (f0d3677), справа ПОСЛЕ; обычная атака, затем Q.
  - `duel-pyro-844-medium` — Пиро: шар обычной атаки и Огненный шар.
  - `duel-grok-844-medium` — Грок: удар вблизи и Удар щитом.
  - `duel-lira-844-medium` — Лира: стрела и Залп.
  - `duel-pyro-667-low` — низкое качество: только кольцо, без искр.
  - `duel-grok-667-reduced` — «уменьшить движение»: фигура не растёт и не разлетается, только гаснет.
- `strip-after-*.jpg` — первые 12 кадров ПОСЛЕ с отметкой времени.
- `crowded-fight-3v3.jpg` — драка 3 на 3: кадр, где одновременно больше всего откликов (ДО — вспышек).
- `full-*-duel-pyro-844-medium.jpg` — кадр целиком в момент попадания Пиро.

Время жизни откликов (игровое): Пиро 0,28 с, Грок 0,22 с, Лира 0,20 с, щит 0,30 с; при «уменьшить движение» не больше 0,20 с.
