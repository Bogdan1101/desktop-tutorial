# Ресурсы GPU при смене матчей

Замер: Chromium, 844×390, среднее качество, модель-робот загружена.
Цикл: выбор героя по кругу (Пиро, Грок, Лира) со скином → матч 3 на 3, все шестеро видимы,
враг погибает и возрождается, 40 с игры с волнами крипов и снарядами → выход в меню.
Числа — `renderer.info.memory` (количество ресурсов, не байты) после отрисовки кадров.
