# Дота 3

Мобильная MOBA в духе League of Legends. Работает прямо в браузере телефона, без установки.

Первая версия: одна линия, по две башни и нексусу у каждой команды, волны крипов и бот-герой в соперниках.

## Как играть

- **Джойстик**: коснитесь левой половины экрана и ведите пальцем.
- **Атака**: удерживайте кнопку, герой бьёт ближайшего врага. Крипов с малым здоровьем он выбирает первыми, так проще добивать.
- **Q, огненный шар**: летит в ближайшего врага, бьёт первого, в кого попадёт.
- **W, рывок**: короткий бросок туда, куда направлен джойстик.
- **E, щит**: на 3 секунды поглощает урон.
- **R, метеор**: открывается с 3 уровня, через секунду падает на врага и бьёт всех в круге.
- **Домой**: 4 секунды стоять на месте, потом телепорт на базу. Любой урон или движение прерывают его.
- **Лавка**: покупки только на своей базе, до 6 предметов.

Золото дают за последний удар по крипу, за убийство героя и разрушенную башню. Цель — разрушить обе вражеские башни и нексус. Башня бьёт героя, который напал на вашего героя рядом с ней, и с каждым выстрелом сильнее.

На компьютере: WASD или стрелки, пробел атакует, 1–4 включают умения, B отправляет домой, P открывает лавку.

## Запуск на компьютере

Нужен любой локальный веб-сервер, потому что браузер не загружает модули с `file://`:

```bash
python3 -m http.server 8000
```

Потом откройте http://localhost:8000.

Режимы для проверки: `?auto` — за синих тоже играет бот, `?auto&speed=4` — то же в 4 раза быстрее.

## Установка на телефон

1. Один раз включите GitHub Pages: **Settings → Pages → Source: GitHub Actions**. После каждого изменения в `main` игра сама выкладывается на `https://<ваш-ник>.github.io/<репозиторий>/`.
2. Откройте эту ссылку в Chrome на Android и выберите **Меню → Добавить на главный экран**. Появится иконка, игра будет открываться во весь экран и работать без интернета.

Отдельное APK-приложение через Capacitor запланировано на следующий шаг.

## Как устроен код

| Файл | Что внутри |
| --- | --- |
| `src/config.js` | Весь баланс: здоровье, урон, перезарядки, предметы, сложность |
| `src/game.js` | Матч: волны крипов, награды, столкновения, фонтаны, победа |
| `src/units.js` | Герой, крип, башня, нексус, снаряды и эффекты |
| `src/ai.js` | Бот-герой: фарм, драки, отступление, покупки |
| `src/world.js` | Карта и проходимые зоны |
| `src/models.js` | Low-poly модели из простых фигур |
| `src/hud.js` | Интерфейс: полоски здоровья, миникарта, кнопки, лавка |
| `src/input.js` | Джойстик, кнопки, клавиатура |
| `src/main.js` | Камера, отрисовка, меню, главный цикл |
| `vendor/three.module.min.js` | 3D-движок Three.js 0.170.0 (лицензия MIT, `vendor/three.LICENSE`) |

Логика матча не зависит от отрисовки, поэтому матч можно прокрутить без экрана: `window.dota3.simulate(секунды)`.

Если вы меняете файлы игры, увеличьте `VERSION` в `sw.js`, чтобы установленная на телефон версия обновилась.
