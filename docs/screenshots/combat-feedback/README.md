# Строка отказа умения и описание умения: до и после

Снято в Chromium (эмуляция телефона, касания, плотность 2×) после окончания анимаций.
Причина в строке — самая длинная: «R Остановка времени: нельзя применять умения».

- `before-*` — коммит 3d54c8d, `after-*` — исправление.
- `normal` — шрифты Google загрузились, `blocked` — запросы к fonts.googleapis.com и fonts.gstatic.com отклонены (системные шрифты).
- `*-fail` — строка отказа; `*-tip` — та же строка, затем удержание кнопки Q открывает описание.
- На каждом листе: 667×375, 844×390, 915×412; слева размер кнопок 1, справа 1,3 (максимум).
- `full-*` — 844×390, кнопки 1,3, в полном размере.

До: текст вылезает за рамку, при кнопках 1,3 строка налезает на миникарту, описание умения ложится поверх строки, при отклонённом запросе шрифтов внизу висит «Ошибка: неизвестная».
