# Узнаваемость героев: до и после

Снято в Chromium (эмуляция телефона, плотность 2×) на обычной игровой камере, без приближения.
В одной сцене все шестеро героев матча 3 на 3: синие спереди, красные сзади, игрок — Пиро с зелёным кольцом.
Туман войны настоящий, боты и крипы остановлены, герои только анимируются. Шрифты Google отключены.

- `before` — коммит bd8799c, `after` — это изменение.
- `1-lane-844-medium-idle-run-attack.jpg` — линия, 844×390, среднее качество: покой, бег, атака.
- `2-jungle-844-667-medium-low.jpg` — тёмный лес, 844×390 и 667×375, среднее и низкое качество.
- `3-lane-844low-667.jpg` — линия: 844×390 низкое, 667×375 среднее и низкое.
- `4-fallback-models.jpg` — `robot.glb` не загрузился (подменён несуществующий файл): запасные модели.
- `5-skins.jpg` — скины игрока: ледяной и золотой Пиро, каменный и золотой Грок, лесная и золотая Лира.
- `full-*.jpg` — кадр целиком, 844×390, среднее качество.
- `anim-before.gif`, `anim-after.gif` — бег, атака, бег, атака, покой; кадры сняты подряд, программный рендер медленный, поэтому темп условный.
